# Contributing

Thanks for your interest in contributing.

## How changes get in

1. Fork the repo and create a branch off `main`.
2. Open a pull request describing what changed and why.
3. All PRs require:
   - At least one approving review from a code owner ([CODEOWNERS](.github/CODEOWNERS))
   - All review conversations resolved
   - A green CI run, once CI checks exist
4. A maintainer will merge once approved.

## Ground rules

- Keep PRs small and focused; large unrelated changes will be asked to split.
- Sign your commits if you can (not required, but appreciated).
- Be respectful in review discussions.

## Reporting bugs

Open a GitHub issue with steps to reproduce. For security vulnerabilities, see
[SECURITY.md](SECURITY.md) instead — do not open a public issue.
