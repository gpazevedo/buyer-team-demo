# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/gpazevedo/buyer-team-demo/security/advisories/new).
You should receive an initial response within 5 business days.

Include, where possible:
- A description of the vulnerability and its impact
- Steps to reproduce
- Affected version/commit

## Supported Versions

Only the `main` branch is supported. There are no maintained release branches at this time.

## Disclosure

We ask that you give us a reasonable window to fix the issue before any public
disclosure. Coordinated disclosure will be credited in the release notes unless
you prefer to remain anonymous.
